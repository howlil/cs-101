> **Masalah:** API transfer masih mengembalikan 201, tetapi refactor mengubah field JSON dan mematahkan consumer yang bergantung pada kontrak lama.

**Mulai:** baca delapan field wajib di schema Transfer dari kontrak SYS-008.

<MentalModel title="Contract drift = rusaknya jaminan provider">

- **Schema drift:** field yang dulu wajib menjadi opsional, atau amount berubah tipe dari string menjadi number.
- **Payload drift:** respons yang dikirim tidak memenuhi schema, walaupun spesifikasinya belum berubah.
- **Additive:** field memo opsional dapat diterima consumer toleran jika additionalProperties true.
- **Batas:** consumer strict masih dapat menolak field baru; test schema tidak membuktikan kompatibilitas semua client.

</MentalModel>

## Matrix perubahan kontrak

| Perubahan | Hasil yang diharapkan |
| --- | --- |
| Hapus currency dari required | Breaking guarantee |
| Ubah amount dari string menjadi number | Breaking type |
| Jadikan memo baru required | Breaking untuk respons lama |
| Tambah memo opsional | Kandidat kompatibel untuk consumer toleran |
| Hilangkan currency dalam body atau kirim EUR | Invalid terhadap baseline |

~~~sh

~~~

