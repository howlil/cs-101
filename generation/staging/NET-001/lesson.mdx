<LessonStage stage="understand">

> **Tujuan:** kamu bisa menelusuri satu request POST /transfers dan membuktikan di mana enam kegagalan berbeda terjadi.

**Mulai:** gambar empat lapisan HTTP → TCP → IPv4 → Ethernet. Ini urutan data **saat dikirim** pada contoh HTTP/1.1 melalui TCP/IP di jaringan Ethernet, bukan susunan universal semua versi HTTP.

## Mengapa perlu?

Log controller yang kosong bukan bukti bahwa backend tidak bermasalah; bisa saja request gagal pada nama host, interface, routing, firewall, TCP listener, atau proxy. Sebaliknya, kode 503 yang diterima client sudah merupakan sebuah **respons HTTP** dari origin atau intermediary.

<MentalModel title="Mental model: boundary sebelum HTTP">

- **Application (HTTP):** method, target /transfers, request body, dan status respons.
- **Transport (TCP):** koneksi antar endpoint dan pengiriman aliran byte pada contoh HTTP/1.1.
- **Internet (IPv4):** alamat dan pemilihan jalur forwarding datagram.
- **Link (Ethernet):** pengiriman frame pada satu segmen jaringan menuju next hop.

Model OSI berguna sebagai penjelas, tetapi implementasi protokol tidak harus tepat tujuh modul. HTTPS menambah keamanan transport; HTTP/3 tidak menggunakan TCP.

</MentalModel>

```sh
node generation/fixtures/NET-001/request-path.mjs
```

Prediksi terlebih dahulu tiga baris output:

```text
http-created=201
http-unavailable=503
connect-error=ECONNREFUSED
```

Dua baris pertama berasal dari respons HTTP. Baris ketiga terjadi setelah listener dihentikan, tanpa respons HTTP.
