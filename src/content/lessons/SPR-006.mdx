> **Target:** implementasikan `POST /transfers` yang menghasilkan HTTP 201 + ID, dan `GET /transfers/{id}` yang menghasilkan 200 atau 404, tanpa business logic dalam controller.

**Mulai:** sebelum menulis kode, tulis tabel kasus: create sukses → 201, get ditemukan → 200, get tidak ditemukan → 404, request tidak valid → 400 (bila validasi dikonfigurasi).

<MentalModel title="HTTP adapter ≠ transfer engine">

Controller menghubungkan **kontrak HTTP** ke **service**. Spring MVC memilih handler melalui method dan path, mengubah body/parameter menjadi nilai Java, lalu menghasilkan respons melalui `ResponseEntity`. Service-lah yang mengurus aturan domain dan penyimpanan. Respons 201 sendiri **tidak menjamin** transaksi atau idempotency aman.

</MentalModel>

## Peta annotation Spring MVC

- `@RestController`: controller yang mengembalikan response body sebagai representasi data.
- `@RequestMapping("/transfers")`: prefix route; `@PostMapping` dan `@GetMapping("/{id}")` memisahkan HTTP method.
- `@PathVariable`: bagian dari path; `@RequestParam`: parameter query/form; `@RequestHeader`: metadata HTTP.
- `@Valid @RequestBody`: binding dan validasi DTO jika ada field constraint serta Bean Validation provider yang terkonfigurasi.
- `ResponseEntity`: status, header (mis. Location) dan response body.

## Contoh controller tipis (ilustrasi Spring MVC)

```java
@RestController
@RequestMapping("/transfers")
class TransferController {
  private final TransferService service;

  TransferController(TransferService service) { this.service = service; }

  @PostMapping
  ResponseEntity<TransferResponse> create(
      @Valid @RequestBody CreateTransferRequest input) {
    Transfer saved = service.create(input);
    var body = new TransferResponse(saved.id());
    return ResponseEntity.created(URI.create("/transfers/" + saved.id())).body(body);
  }

  @GetMapping("/{id}")
  ResponseEntity<TransferResponse> find(@PathVariable String id) {
    return service.findById(id)
        .map(found -> ResponseEntity.ok(new TransferResponse(found.id())))
        .orElseGet(() -> ResponseEntity.notFound().build());
  }
}
```

`CreateTransferRequest`, `TransferResponse`, `Transfer`, dan `TransferService` adalah tipe aplikasi yang **harus kamu implementasikan**. Tambahkan constraint misalnya `@NotBlank` dan `@Positive` serta dependency `spring-boot-starter-validation` jika ingin validasi DTO. Contoh ini tidak menyertakan database, authorization, atau transaksi dana.
