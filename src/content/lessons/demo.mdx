## Konsep

Sebuah kondisi menentukan cabang yang dijalankan. Mulai dari input, evaluasi kondisi, lalu ikuti satu cabang.

<MentalModel title="Input → kondisi → hasil">
  Ubah satu input, lalu prediksi apakah hasilnya ikut berubah.
</MentalModel>

## Contoh

```js
const score = 7;
const passed = score >= 8;
console.log(passed); // false
```

Nilai `7` lebih kecil dari `8`, sehingga kondisi bernilai `false`.

## Latihan

<Quiz items={[{ question: 'Jika score menjadi 8, apa nilai passed?', options: ['true', 'false'], answer: 0, explanation: 'Operator >= menerima nilai yang sama dengan batasnya.' }]} />

<Reveal title="Kenapa nilai batas perlu diuji?">
  Input tepat pada batas membantu membedakan perilaku `>` dan `>=`.
</Reveal>

<Challenge title="Coba nilai batas" brief="Jalankan contoh dengan score 7, 8, dan 9." acceptanceCriteria={['Prediksi hasil sebelum menjalankan kode.', 'Jelaskan perbedaan > dan >= pada input 8.']} />
