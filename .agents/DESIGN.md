## Direction
Product: compact, research-grade cross-domain engineering library.
Character: neutral, text-forward and diagrammatic.
World: preserve existing monochrome tokens and Plus Jakarta Sans.
Moment: a focused concept, a numbered study route and a compact assessment rubric tied to canonical units.
Signature: deterministic interactive bounded one-hop/two-hop node–edge map, with semantic links and evidence list retained below; never a physics-based invented curriculum graph.

## Guardrails
No shadows, invented lessons, progress badges, new persistence, or duplicate sidebar.
## State
Mode, selected concept, G0–G4 depth and optional lesson path context belong to URL query params.
## Patterns
In mapped lessons, show one reusable compact-context canvas after the article, never over the first reading paragraph. Unmapped units link to Graph without suggesting missing edges.
Canvas nodes are native SVG links; pointer drag pans empty space, buttons zoom/reset, arrow keys pan the focused viewport, and the existing text links are always available as fallback. The URL owns selected concept/depth; viewport controls are local and reset on navigation. Show only curated edges at the active level; the full Graph can locally toggle 1/2 hops, while lesson previews remain one hop. Expand rings deterministically, bound the node count, and show two-hop native text-link fallback. Dashed means proposed, not a prerequisite; solid reviewed edges retain direction in data. Study route and rubric remain readable lists. On mobile, horizontal canvas scroll and text links preserve access; missing depths are explicit.
## Accessibility
Keyboard, visible focus, semantic labels and readable text alternatives are mandatory.
